# Orientações para trabalhar no Kotonoha

- Antes de criar ou redesenhar interface, conteúdo visual ou identidade, consulte e aplique as skills de design instaladas que forem relevantes. Priorize `ui-ux-pro-max`, `ui-styling`, `design-system` e `brand` para trabalho de produto; use apenas as que contribuam para a tarefa.
- Para ilustrações personalizadas do produto, use o plugin Anidoodle instalado no Codex e siga as instruções de intake, estilo, criação e revisão da skill do plugin.
- Preserve a identidade do Kotonoha, a acessibilidade, o uso em celular e desktop e todas as funcionalidades existentes. Não aplique skills de design a tarefas de código sem relação com design.
- Direção de interface e decisões aprovadas ficam documentadas em `design-system/kotonoha/MASTER.md`.
